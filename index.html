Every one of these is live and open right now. Open a project to read what it needed and how it was solved — or load the real thing in the page and click around it yourself. 以下每一個都還在線上運作中。展開可以看到當初的需求與解法，也可以直接把成品載進這一頁，自己動手點點看。

  1. 01

    Evergreen Dental常青牙醫診所

    A clinic site built around a four-step online booking flow. 以四步驟線上預約為核心的診所網站。

    Booking flow · Bilingual · No framework 線上預約 · 中英雙語 · 無框架

    The brief

    A dental clinic loses bookings every time someone has to call during opening hours. The site had to take the appointment itself, on a phone, in either language.

    What I did

    A four-step booking flow that validates as you go, with a clickable error summary so nobody hunts for the field they missed, and honest loading, success and failure states. Both languages are set with their own typography, not one layout with the words swapped.

    Worth knowing

    No framework and no build step — plain HTML, CSS and JavaScript. It loads fast on a phone on mobile data, and it can be handed to any developer later without a lecture.

    當初的需求

    診所每次要求客人「上班時間打電話預約」，就會流失一些預約。網站本身必須能收單，手機上要好操作，中英文都要能用。

    我做了什麼

    四步驟預約流程，每一步即時驗證；錯誤總覽可以直接點回該欄位，不用自己找漏填哪一格；載入中、成功、失敗的狀態都完整交代。中英文各有各的排版設定，不是同一套版型換掉文字而已。

    技術重點

    沒有用框架，也沒有打包流程，就是純 HTML、CSS 跟 JavaScript。手機用行動網路開也很快，日後要轉交給其他工程師接手，不需要額外教學。

  2. 02

    CineScopeCineScope 電影探索

    A film discovery app, and the piece that shows how I handle real data. 電影探索應用，也是最能看出我怎麼處理真實資料的一件作品。

    React · TypeScript · Live API React · TypeScript · 串接即時 API

    The brief

    Something to search a live film database, keep a personal watchlist, and survive being shared as a link — set myself, to prove out the parts of a build that clients never see but always feel.

    What I did

    Search that cancels its own stale requests, so typing quickly can't leave you looking at results for a word you already deleted. Deep links you can send to someone. A watchlist that persists. Light and dark themes that both pass contrast.

    Worth knowing

    The API key is not in the website. It lives as a secret on a small Cloudflare Worker that sits in front of the film database and only forwards three approved requests. A site that calls the API directly has to ship its key to every visitor's browser — anyone can read it and spend your quota. This is the part I would want a client to ask me about.

    當初的需求

    想做一個能搜尋即時電影資料庫、能存個人待看清單、而且丟連結給別人也不會壞掉的東西。這是我自己出的題目，用來練那些客戶看不見、但一定感受得到的環節。

    我做了什麼

    搜尋會自動取消過期的請求，所以打字快一點也不會看到早就刪掉的關鍵字結果。每個頁面都有可以直接分享的連結。待看清單會保存下來。深淺兩種配色的對比度都有通過檢查。

    技術重點

    API 金鑰沒有放在網站裡。它是存在一個小型 Cloudflare Worker 上的機密設定，由它擋在電影資料庫前面，只放行三種允許的請求。如果網站直接呼叫 API，金鑰就得跟著送到每一位訪客的瀏覽器，任何人都讀得到，也花得掉你的額度。這一段是我最希望客戶開口問我的部分。

  3. 03

    EcholoopEcholoop 語言跟讀訓練

    A listening and shadowing trainer that scores your pronunciation in the browser. 在瀏覽器裡就能評分發音的聽力與跟讀練習工具。

    React · Audio & speech · Works offline React · 語音處理 · 可離線使用

    The brief

    I wanted a shadowing tool for my own language practice and could not find one that did not want an account and a subscription.

    What I did

    It records you speaking, uses the browser's own speech recognition to judge how clearly each word came through, and quietly collects the lines you keep fumbling into a review list. Eight languages.

    Worth knowing

    No accounts, no server, no analytics — your voice never leaves the device. It also keeps working with the plane's wifi off. Proof that "we need a backend for this" is often not true, which usually shows up on a client's invoice as a hosting bill they never have to pay.

    當初的需求

    我自己想練跟讀，但找來找去，每一套工具都要註冊帳號、還要訂閱付費，乾脆自己做一個。

    我做了什麼

    錄下你的發音後，用瀏覽器內建的語音辨識判斷每個字說得夠不夠清楚，並把一直卡住的句子默默收進複習清單。支援八種語言。

    技術重點

    不用註冊、沒有後端、也沒有任何追蹤分析，你的聲音完全不會離開你的裝置；飛機上關掉網路也照樣能用。這件作品證明了「這個一定要有後端」通常不成立，而這件事反映在客戶帳單上，就是一筆從頭到尾都不用付的主機費。

  4. 04

    Movies Watchlist電影待看清單

    The same idea as CineScope, built earlier with no framework at all. 跟 CineScope 同樣的題目，但這是更早期、完全沒用框架的版本。

    Vanilla JavaScript · API · Local storage 原生 JavaScript · 串接 API · 本機儲存

    Why it is still here

    Search against the OMDb film database, a saved watchlist, detail modals and a dark mode that remembers itself — all in plain JavaScript, no framework, no build tooling.

    Worth knowing

    I kept this alongside CineScope on purpose. Put them side by side and you can see the same problem solved with and without React, which is the clearest evidence I can offer that I pick tools rather than default to them.

    為什麼還留著這件

    串接 OMDb 電影資料庫的搜尋、可保存的待看清單、詳細資訊彈窗，還有會記住設定的深色模式，全部用原生 JavaScript 完成，沒有框架，也沒有打包工具。

    技術重點

    我是刻意把它跟 CineScope 一起留著的。兩件擺在一起看，就是同一個題目分別「用 React」跟「不用 React」的解法。要證明我是在挑工具、而不是無腦套框架，這是我拿得出來最清楚的證據。

02 — How it works02 — 合作方式

What happens after you email me. 來信之後，會發生什麼事。

  1. 1

    We talk先聊聊

    A call or a few emails, in whichever language you prefer. You tell me what the business actually needs. If a website is the wrong answer, I will say so. 一通電話或幾封信，中英文都可以，看您方便。您說明生意上真正的需求。如果做網站根本解決不了問題，我會直說。

  2. 2

    Scope and quote確認範圍與報價

    Before any work starts, you get a written list of what is included and what it costs. If something is out of scope later, we agree on it before I build it. 動工之前，先給您一份書面清單：做哪些、多少錢，寫清楚。後續如果有超出範圍的項目，一定先講好再動手。

  3. 3

    Build in the open開發過程公開

    You get a link from day one. Open it on your phone, send it to your staff, tell me what is wrong while it is still cheap to change. 第一天就給您一組連結。手機打開、轉傳給同仁都行。有問題趁早講，那時候要改還很便宜。

  4. 4

    Handover交付上線

    It goes live on your own domain. You get the code and a short plain guide for changing your own text, so you are never stuck waiting on me for a typo. 上線到您自己的網域。程式碼交給您，另外附一份白話的說明，教您自己改文字，以後打錯一個字不用還要等我。

03 — Approach03 — 我的作法

Four things I will not cut corners on. 四件我不會偷工減料的事。

  • Customers can find you客人找得到你

    Built to be found on Google — and to look right the moment someone shares you on LINE. Google 搜得到，別人轉貼到 LINE 的時候，預覽也是好看的。

  • It works on a phone手機上就是好用

    Designed for the small screen first, because that is where your customers already are. 一律從小螢幕開始設計，因為你的客人本來就都在手機上。

  • Two languages, done properly中英雙語，做到位

    Each language typeset on its own terms — the thing the switch at the top of this page is doing. 兩種語言各排各的版，就是這一頁最上面那顆切換在做的事。

  • You are not locked in不會被我綁住

    Plain code you own outright, hosted anywhere you like. Nothing breaks if we stop working together. 程式碼完全是你的，主機想放哪就放哪。哪天不合作了，網站也不會出事。

HTML, CSS, JavaScript, TypeScript, React — chosen per job, not by habit. HTML、CSS、JavaScript、TypeScript、React —— 依案子挑選，不是習慣性套上去。
